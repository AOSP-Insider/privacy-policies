# Privacy policies

Privacy policies for apps and games by Samir Dubey, served with GitHub Pages:
https://aosp-insider.github.io/privacy-policies/

| App | Policy |
| --- | --- |
| Tumble Sort: Gravity Box (`com.sdcode.tumblesort`) | https://aosp-insider.github.io/privacy-policies/tumble-sort/ |

To add an app, create a folder named after it with an `index.html` (copy `tumble-sort/index.html`), then link it from `index.html` and this table.

`apps/` holds small public JSON config files that apps read at start (for example `apps/tumble-sort/config.json`).
